# connection 10.0.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make `@mcp-abap-adt/connection` the process of `@mcp-abap-adt/interfaces-auth` 3.0.0's `IAuthProvider`: any provider, called the same way — `prepare`, `establish` per logon, `authorize` per attempt, `rejected` on a refused credential — with the wires implementing the targets.

**Architecture:** The lifecycle (`AbstractAbapConnection`) gets four provider-agnostic hooks with neutral defaults; `CredentialAbapConnection` implements them by calling the provider, guarded. The wires receive `authorize(headers)` / `logon(target)` in the session context instead of `authHeaders()`; HTTP takes TLS material at logon, RFC takes logon parameters on every conversation it opens. Refusals go out as `AuthRefusedError`; a wire marks a failed logon with `WireLogonError` and decides nothing.

**Tech Stack:** TypeScript (CommonJS output, `.js` import suffixes), Jest (`npm test`, `npx jest --testPathPatterns=<name>`), Biome, axios, `@mcp-abap-adt/sap-rfc-lite` (optional).

**Spec:** `docs/superpowers/specs/2026-09-30-connection-10-design.md`, answering to `docs/superpowers/2026-09-30-connection-10-goal.md` (rules H1–H7). Read both before any task.

## Global Constraints

- `@mcp-abap-adt/interfaces-auth` `^3.0.0`; `@mcp-abap-adt/interfaces-auth-sap` `^1.1.0`; `@mcp-abap-adt/auth-providers` `^5.0.1` in **devDependencies only** (H6).
- Nothing in `src/` (outside `__tests__`) branches on `credential.kind`, uses `instanceof` on a provider, or reads `config.username` / `config.password` to authenticate (H1, H2).
- After Ok from `rejected()`: exactly one more attempt; a second refusal is the verdict (H5).
- Fixed wordings, verbatim: `'the credential provider failed'`; `'the credential was refused again after the provider renewed it'`; `'this wire takes no logon parameters (HTTP)'`; `'this wire carries no TLS material (RFC)'`; `'this connection has no credential to renew'`.
- Local imports end in `.js`; Node built-ins use `node:`; single quotes, semicolons, 2-space indent (Biome).
- Tests live in `src/__tests__/`; they are excluded from `tsc` build but type-checked by Jest.
- `version` becomes `10.0.0` only in Task 7.

## Review Focus

1. **A provider that throws** instead of answering (a consumer's own provider) — expect Oops `'the credential provider failed'` with the throw as `cause`, never an unhandled rejection. Test: Task 2, "a provider that throws".
2. **Concurrent requests meeting the same 401** — expect each to call `rejected()` once and resend once; no request loops, none hangs. Test: Task 3, "two concurrent 401s each ask once and resend once".
3. **A 401 inside a critical section (lock held)** — expect the resend on the same session, the lock handle still valid, no `SESSION_REPLACED`. Test: Task 3, "a renewal inside a critical section keeps the session".
4. **An RFC per-call conversation whose logon fails mid-session** (SNC client logged out after connect) — expect `rejected({ at: 'logon', error: <raw> })` and the provider's words, not "Failed to open RFC connection". Test: Task 5, "a per-call logon failure goes to the provider raw".
5. **A certificate that changes between logons** — expect the next request on a new agent with the new material, the cookie jar kept. Test: Task 4, "different material rebuilds the client and keeps the jar".

`src/connection/authErrors.ts`:

```ts
/**
 * What the connection raises when authentication ends a call, and how a wire
 * says a logon failed.
 *
 * `AuthRefusedError` carries the provider's own words (goal H3); the wire's
 * error travels beside them as `cause`, so a network failure stays visible even
 * when a provider words it as a credential problem. `WireLogonError` is a
 * mark and nothing more (H4): the lifecycle decides what follows.
 */

import type { AuthOutcome, IAuthRefusal } from '@mcp-abap-adt/interfaces-auth';

export type AuthRefusalMoment = 'prepare' | 'logon' | 'request';

export const PROVIDER_FAILED: IAuthRefusal = {
  reason: 'the credential provider failed',
};

/** The one refusal the connection words itself: the provider's last word was Ok. */
export const REFUSED_AGAIN: IAuthRefusal = {
  reason: 'the credential was refused again after the provider renewed it',
};

export const NO_CREDENTIAL_TO_RENEW: IAuthRefusal = {
  reason: 'this connection has no credential to renew',
};

export class AuthRefusedError extends Error {
  readonly refusal: IAuthRefusal;
  readonly at: AuthRefusalMoment;
  override readonly cause?: unknown;

  constructor(refusal: IAuthRefusal, at: AuthRefusalMoment, cause?: unknown) {
    super(
      refusal.hint ? `${refusal.reason} — ${refusal.hint}` : refusal.reason,
    );
    this.name = 'AuthRefusedError';
    this.refusal = refusal;
    this.at = at;
    this.cause = cause;
  }
}

export class WireLogonError extends Error {
  readonly status?: number;
  override readonly cause: unknown;

  constructor(cause: unknown, status?: number) {
    super(
      status === undefined
        ? 'the logon was refused'
        : `the logon was refused (${status})`,
    );
    this.name = 'WireLogonError';
    this.cause = cause;
    this.status = status;
  }
}

/**
 * A provider must not throw across the contract; a consumer's own may. A throw
 * is its Oops, with the throw kept for the cause.
 */
export async function guarded(
  call: () => Promise<AuthOutcome>,
): Promise<{ outcome: AuthOutcome; thrown?: unknown }> {
  try {
    return { outcome: await call() };
  } catch (thrown) {
    return { outcome: { ok: false, refusal: PROVIDER_FAILED }, thrown };
  }
}
```

`src/connection/requestTarget.ts`:

```ts
/**
 * The one request target every wire shares.
 *
 * The wires already carry request headers where they must go — HTTP merges
 * `Cookie` with its jar, RFC forwards every header as a
 * `SADT_REST_RFC_ENDPOINT` field — so a provider writing into the request's
 * headers reaches every wire without one of its own.
 */

import type { IRequestTarget } from '@mcp-abap-adt/interfaces-auth';
import { mergeCookieHeaders } from '../utils/cookies.js';

export function requestTargetOn(
  headers: Record<string, string>,
): IRequestTarget {
  return {
    header(name, value) {
      headers[name] = value;
    },
    cookies(value) {
      headers.Cookie = mergeCookieHeaders(headers.Cookie, value);
    },
  };
}
```

`src/__tests__/helpers/stubProvider.ts`:

```ts
/**
 * A provider that records every call and answers as scripted.
 *
 * `authorize` writes `Authorization: Stub <n>`, where `n` counts the Ok answers
 * `rejected` has given — so a test sees whether a resend carried the renewed
 * credential.
 */

import type {
  AuthOutcome,
  IAuthProvider,
  IAuthRejection,
  ILogonTarget,
  IRequestTarget,
} from '@mcp-abap-adt/interfaces-auth';

export type StubCall =
  | { moment: 'prepare' }
  | { moment: 'establish' }
  | { moment: 'authorize'; wrote: string }
  | { moment: 'rejected'; rejection: IAuthRejection };

export interface StubScript {
  prepare?: () => Promise<AuthOutcome>;
  establish?: (logon: ILogonTarget) => Promise<AuthOutcome>;
  /** Answers per call, in order; the last repeats. Default: Ok. */
  rejected?: AuthOutcome[];
  authorize?: (request: IRequestTarget, renewals: number) => Promise<AuthOutcome>;
}

export interface StubProvider extends IAuthProvider {
  readonly calls: StubCall[];
  count(moment: StubCall['moment']): number;
}

export function stubProvider(script: StubScript = {}): StubProvider {
  const calls: StubCall[] = [];
  let renewals = 0;
  let rejectedAsked = 0;
  return {
    kind: 'stub',
    calls,
    count: (moment) => calls.filter((c) => c.moment === moment).length,
    async prepare() {
      calls.push({ moment: 'prepare' });
      return script.prepare ? script.prepare() : { ok: true };
    },
    async establish(logon) {
      calls.push({ moment: 'establish' });
      return script.establish ? script.establish(logon) : { ok: true };
    },
    async authorize(request) {
      if (script.authorize) {
        calls.push({ moment: 'authorize', wrote: '(scripted)' });
        return script.authorize(request, renewals);
      }
      const value = `Stub ${renewals}`;
      request.header('Authorization', value);
      calls.push({ moment: 'authorize', wrote: value });
      return { ok: true };
    },
    async rejected(rejection) {
      calls.push({ moment: 'rejected', rejection });
      const answers = script.rejected ?? [{ ok: true }];
      const answer = answers[Math.min(rejectedAsked, answers.length - 1)];
      rejectedAsked += 1;
      if (answer.ok) renewals += 1;
      return answer;
    },
  };
}
```

import { createServer, type IncomingHttpHeaders, type Server } from 'node:http';

  method: string;
  url: string;
  headers: IncomingHttpHeaders;
}

export interface SapStub {
  baseUrl: string;
  seen: SeenRequest[];
  /** Statuses for the next work requests, first in first out; then 200. */
  work: Array<{ status: number; body?: string }>;
  /** Statuses for the next discovery requests; then 200 with a token. */
  discovery: Array<{ status: number }>;
  close(): Promise<void>;
}

export async function startSapStub(): Promise<SapStub> {
  const stub = {
    seen: [] as SeenRequest[],
    work: [] as Array<{ status: number; body?: string }>,
    discovery: [] as Array<{ status: number }>,
  };
  let issued = 0;
  const server: Server = createServer((req, res) => {
    stub.seen.push({ method: req.method ?? '', url: req.url ?? '', headers: req.headers });
    const url = req.url ?? '';

        res.end('refused');

      });
      res.end('<service/>');
      return;
    }
    if (url.includes('/icf/logoff')) {
      res.writeHead(200);
      res.end();
      return;
    }
    const next = stub.work.shift() ?? { status: 200, body: 'ok' };
    res.writeHead(next.status, { 'content-type': 'text/plain' });
    res.end(next.body ?? '');
